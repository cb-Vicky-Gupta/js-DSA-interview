# 🚀 Mid-Level Product-Based DSA Interview Questions

A curated list of data structures and algorithms questions frequently asked in mid-level product-based company interviews.

---

### 🟢 Q1 — Arrays (Easy)

**Problem:**  
Given an array of integers, find the two numbers that add up to a target sum. Return their indices.

**Example:**
```plaintext
Input: [2, 7, 11, 15], target = 9
Output: [0, 1]
```

---

### 🟢 Q2 — Strings (Easy)

**Problem:**  
Check if a string is a valid palindrome, considering only alphanumeric characters and ignoring case.

**Example:**
```plaintext
Input: "A man, a plan, a canal: Panama"
Output: true
```

---

### 🟡 Q3 — Sliding Window (Medium)

**Problem:**  
Given an array of positive integers and a number `k`, find the maximum sum of any contiguous subarray of size `k`.

**Example:**
```plaintext
Input: [2, 1, 5, 1, 3, 2], k = 3
Output: 9
```

---

### 🟡 Q4 — Linked List (Medium)

**Problem:**  
Given the head of a linked list, detect if there is a cycle in it. How would you do it with `O(1)` extra space?

> *(No need to code — explain your approach clearly)*

---

### 🟡 Q5 — Trees (Medium)

**Problem:**  
Given the root of a binary tree, return its level-order traversal (values level by level, left to right).

**Example:**
```plaintext
Input tree:
    3
   / \
  9  20
    /  \
   15   7

Output: [[3], [9, 20], [15, 7]]
```
